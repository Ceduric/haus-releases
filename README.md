# haus releases

Test versions of haus, Studio Niederhaus's Mac app, and the update lists it reads (`appcast-<tools>.xml`).
A copy of haus opens only with a key from Cedric. Nothing else lives here: no source, no names.

- `appcast-manifest.xml`: haus with manifest; the disk images in `manifest/`
- `switched-off.txt`: keys switched off before their date (ids only)

Made by `scripts/release.sh` in the haus repository.
